Accessibility Statement

Kotech aims to make learning resources easy to access and use for as many people as possible.

1. Our Goal

We aim to make our website understandable, readable, and usable across different devices and abilities.

2. Website Design

We aim to provide clear headings, readable text, sufficient colour contrast, and layouts that adapt to different screen sizes.

3. Keyboard Navigation

Links and controls should be accessible using a keyboard wherever possible.

4. Images and Text

Meaningful images should include alternative text so that people using screen readers can understand their purpose.

5. Report an Accessibility Problem

If you experience difficulty using Kotech, please contact us through the contact information available on our website.
