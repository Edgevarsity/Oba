��# Kotech Homepage

This project contains the landing page for the Kotech website. It is designed to showcase courses, categories, instructor highlights, and other learning platform content.

## Overview

The homepage includes:
- a top navigation bar with links to courses, accounts, products, videos, and cart
- a search area for browsing topics
- a hero section encouraging users to explore courses
- featured course cards
- category highlights
- instructor and learning sections

## Files

- `index.html` — homepage structure and content
- `index.css` — visual styling and layout
- `index.js` — homepage interactivity and behavior

## How to view it

Open `index.html` in a browser to see the landing page.

You can also run the site from the project folder using a local web server and open the homepage in the browser.

## Purpose

This page acts as the main landing page for the Kotech learning platform and helps users discover courses, products, and educational content quickly.

1. Open Visual Studio Code.
2. Open the Kotech project folder.
3. Find `index.html`.
4. Right-click the file.
